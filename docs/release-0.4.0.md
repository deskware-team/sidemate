# 桌伴 0.4.0

0.4 是一次小版本优化：成品和材料能在桌伴里直接预览；对话里能直接看统计图、流程图、公式和图片；新闻改成「一句话 + 几点出」，可以订好几个；小岛的动作更顺，干活时会跟着换神情。

这版还是只支持 Windows。

## 从 0.3 升级

- 直接装新版就行，不用先卸载。0.3 的钥匙、对话、新闻和设置都接着用，不用重新配置。
- **新闻**：0.3 订的主题都留着。订了好几个的，每个主题的名字和关注内容合成一句话，比如「AI 行业：大模型和 AI 应用的最新动态」，原来的 `news.json` 备份成 `news.json.bak-0.4`。主题名改成从这句话里自动总结，也可以自己改。
- **新闻不再补生成**：「休眠错过后补生成」这个开关去掉了。到点时电脑在睡、或者桌伴没开着，那一次就不生成，右键「新闻订阅」里那一天会写「未生成：桌伴未运行」；想要的话进设置点「立即生成」。
- 用过 Kilo 模型的：《Kilo 模型使用须知》升到了 1.1，下次用 Kilo 时会先请你看一遍、重新同意。

## 新增

- **预览**：成品卡上点「预览」，或者点任务窗右上角的预览按钮，在桌伴里直接看 Word、PPT、PDF、Excel、图片和网页，不用打开别的程序。
  - 左边列出这次对话的成品和材料，点哪份看哪份。
  - 底栏可以缩放：适应宽度，或者 50% 到 200%；Ctrl 加滚轮也行。
  - 顶上是「打开」「在文件夹里显示」「另存为」。成品卡上点右键，也有「预览」「打开」「在文件夹里显示」「另存为」。
- **对话里的图**：模型在回话里就能画柱状图、折线图、饼图和流程图，也能显示公式和工作区里的图片。图上点右键，可以另存为图片或者复制。
- **新闻**：
  - 每个主题一张卡：说一句想看什么，再定频率（每天、工作日、每周一）和几点出。最多订 5 个。
  - 主题名从那句话里自动总结，最多 8 个字；不满意就点一下自己改。
  - 点「立即生成」以后看得到进度：卡片上写「正在生成… 已用 1 分 20 秒」，小岛进入干活的样子；生成完写「今天 08:31 已生成 · 9 条」，点「看看」直接打开。
  - 后台生成时能不能跑命令、改文件，整页一个开关，默认关着。
- **任务列表**：左上角「任务列表」里，每条对话的时间左边多了一个标记：转圈是还在跑，绿点是在后台做完了、你还没回去看。

## 改进

- **小岛**：眼睛的动作改成弹簧带动，换表情时不跳；干活时跟着读材料、想、写换神情；10 分钟没动静先打个盹再睡着，鼠标靠近会慢慢醒过来。高刷新率屏幕上，动画最多 60 帧；电脑很忙的时候，小岛先停下东张西望这些小动作。
- **回话一个字一个字冒出来**：不用等一整段写完。
- **几个任务一起跑更顺**：以前几个任务同时跑时，桌伴偶尔会卡一下，这个修好了。
- **工具偶尔失败时**：对话里不再单独冒一行「调用失败」，由模型自己换个办法接着做。
- **什么时候交文件**：让它写通知、报告这类要交出去的材料，它交 Word；只是让它搜一搜、问个问题、列个清单，它直接在对话里回答。
- **Office 成品交出去之前自查一遍**：材料里没有的时间、地点、数字不编，缺了就写「待定」并说一声；Excel 里的合计、环比写成公式。
- **设置**：删除模型、技能、外部工具和新闻主题之前，确认改成窗口里的小窗；首次运行每一屏的内容都在窗口里居中。

## 安装

1. 下载下面的 `sidemate-setup-0.4.0.exe`，双击安装。安装包没有签名，Windows 弹出提示时，点「更多信息」，再点「仍要运行」。
2. 第一次打开：先看几句说明，点「开始」；贴上 DeepSeek 的 API key 点「测试」，也可以自己配置别的模型。测试通过就能用了。
3. 从 0.3 升上来的，直接装，见上面「从 0.3 升级」。

## 卸载

卸载时只问一次「确定卸载桌伴吗？」。下面有一个默认不勾的选项「同时删除全部配置和记录（包括任务里生成的文件，删除后无法恢复）」；不勾就只删程序，对话和文件都留着。

## 已知问题

- 一段对话做完、你离开这段对话以后，拖进来的材料副本会被清掉，预览窗里就只剩成品了；要看材料，请打开原来的文件。
- 刚装好第一次打开时，可能会卡一两秒。
- 安装包没有签名，Windows 第一次会拦一下。
- 只在 Windows 10 / 11 上测过。

## 隐私

桌伴没有账号和服务器，不收集使用数据。用 Kilo 模型时，内容会传到 Kilo AI 处理。详见 [PRIVACY.md](../PRIVACY.md)。
