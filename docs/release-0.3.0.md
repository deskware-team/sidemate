# 桌伴 0.3.0

本项目基于DeepseekHarness开发，桌伴是你的小伙伴，贴在屏幕顶上，平时只露一双眼睛。0.3 版本支持DeepSeek、Kilo或者BYOK、支持Skills、MCP，新增新闻功能（在你想要的时间送上一份你关心的内容）。

这版还是只支持 Windows。

## 从 0.2 升级前先看

- **0.2 的钥匙、对话、新闻和设置，0.3 都不读。** 0.3 的数据换到了 `%LOCALAPPDATA%\sidemate`。装好以后第一次打开，要像新装一样重新选模型、贴一次钥匙。
- **0.2 的文件没删。** 0.2 写出来的文件和它自己的记录都还在 `C:\Users\<你的用户名>\桌伴` 里，要用的话去那儿拿；不要了可以自己删掉这个文件夹。
- **这几样 0.2 的做法变了：**
  - 拖进来的不再分左边范本、右边材料，都叫文件。要照哪一份的格式写，在话里说一句就行。
  - 不再在 Word 批注里给每句标出处。
  - 成品不再放进「桌伴输出」文件夹，在对话里的成品卡上打开、另存为，或者打开所在文件夹。

## 能做什么

### 新增

- **多供应商模型**：
  - **DeepSeek**：贴上自己的 API key，按用量付费，支持DeepSeek原生工具。
  - **Kilo**：使用 Kilo 的网关，有次数限制，详见程序中的Kilo通道说明和官方的说明。
  - **自定义**：填地址、模型名和API key，OpenAI 格式和 Anthropic 格式的接口都行。
  - **装Skills、连MCP**（设置 · 能力）：
  - **技能**：导入一个文件夹或一个 .zip 就能装上。也可以在对话里说「帮我装 xxx 技能」，它先给你一张确认卡，写清装什么、从哪下，你点了「装上」才下载。对话里装的技能，设置里会标出来源仓库、提交号和许可证。
  - **MCP**：填网址、把别处复制来的配置粘进去，或者填一个本机程序（程序、参数、环境变量），就能连上外面的服务。服务的密钥只给这个服务用，不会传给模型写的脚本。
  - **自带的**：「写材料」，和推荐的「画流程图」（流程图、分工图、时间线，画出来是 Word / PPT 里能直接改字、拖位置的方框和箭头）。都默认开着。
- **新闻**（设置 · 新闻）：
  - 说一句想看什么、什么时候看，到点你的模型自己去搜、自己去读原文，每条都带这一轮真打开过的链接。也可以点「立即生成」。
  - 要能联网搜：配一把 DeepSeek key，或者在「能力」里加一个能搜索的工具。
  - 每个主题可以选「自动配置权限：允许 / 拒绝」。拒绝的话，模型生成时要额外权限的操作会被拒掉，可能导致生成失败。
  - 生成好了小岛会提醒你；右键小岛选「新闻订阅」，按主题按天翻。新闻只在桌伴里看，在那份新闻的对话里说「转成 Word」才给你文件。
  - 电脑休眠错过了时间，醒来会补一份（设置里能关）；桌伴没开着的时候不生成。
- **任务窗**：
  - **先回一句再干活**：发出去以后，模型先用一句话说打算怎么做，再动手。
  - **干到一半能插话**：插的那句马上送过去。
  - **成品卡**：做出来的文件在对话里是一张卡，能打开、另存为、打开所在文件夹，也能直接拖到桌面或别的程序里。
  - **接着聊**：做完了再说一句，或者再拖一个文件进任务窗，都接着这段对话；左上角「任务列表」里能翻以前的对话，挑一段接着聊。
  - **贴东西**：图片直接贴进去；贴的长文字自动存成文件。
  - **要权限时问你**：模型要做超出范围的操作时弹一张卡，可以「允许一次」「本任务都允许」或「拒绝」。
  - **读网页不碰本机**：模型读链接时默认不访问本机和局域网里的地址；要访问的话在设置里打开「允许访问本地网络」。
- **右键「最近」**：最近在里面干过活的文件夹和最近的任务，点一下就打开。
- **看着顺眼**（设置 · 显示）：字号四档（小、标准、大、特大），小岛大小可调；任务窗里按 Ctrl 加号 / 减号也能调字号，Ctrl + 0 回到标准。

### 改进

- **后台常驻**：干活的进程一直开着，开新任务更快；它万一崩了会自己重起，正在跑的任务点「继续」接着做。
- **出错说得清楚**：会说清是哪一步、可能是什么原因、接下来怎么办，后面带一个短错误码（比如 Si901），反馈时带上就行。模型那边忙或断线时，它自己等一会儿再试，等的时候有倒计时。
- **窗口**：首次运行、设置、使用须知这几个窗去掉了系统标题栏，开在屏幕正中，右上角是圆形的关闭钮。
- **新图标**：深色圆角方块上一双眼睛，浅色任务栏上也看得清。
- **卸载只问一次**：见下面「卸载」。

## 怎么用

- 小岛贴在屏幕顶边，左右拖动能换位置。鼠标停在上面会冒一行字；有事时眼睛会变：干活时往下看稿子，做完了是笑眼，等你回话时睁大眼睛、亮一个红点。
- 点一下小岛，任务窗从它下面垂下来；再点一下就收起，活接着干。
- 文件拖到小岛上，小岛往两边长开、写「松手交给我」，松手就开一件新事；拖进任务窗是接着这段对话。
- 右键小岛可以选「新闻订阅」「新任务」「最近」「设置」「置顶」。
- 设置 · 用量里能看这个月用了多少，以及最近 10 个任务各用了多少。

## 安装

1. 下载下面的 `sidemate-setup-0.3.0.exe`，双击安装。安装包没有签名，Windows 弹出提示时，点「更多信息」，再点「仍要运行」。
2. 第一次打开：先看几句说明，点「开始」；接着选一个模型——贴上 DeepSeek 的钥匙点「测试」，或者选 GLM、Kilo 模型，也可以自己配置。测试通过就能用了。
3. 从 0.2 升上来的，先看最上面那一节：要重新贴一次钥匙。

## 卸载

卸载时只问一次「确定卸载桌伴吗？」。下面有一个默认不勾的选项「同时删除全部配置和记录（包括任务里生成的文件，删除后无法恢复）」；不勾就只删程序，对话和文件都留着。

## 已知问题

- Kilo 模型有次数限制，额度和可用性由 Kilo AI 决定；用满了要等一阵才恢复，急的话换个模型接着干。
- 只用 Kilo 模型的人暂时订不了新闻：新闻要模型能联网搜，要么配一把 DeepSeek key，要么在「能力」里加一个能搜索的工具。
- 当前模型不支持图片输入时，带图片的那句发不出去，会提醒你换一个能看图的模型。
- 安装包没有签名，Windows 第一次会拦一下。
- 只在 Windows 10 / 11 上测过。

## 隐私

桌伴没有账号和服务器，不收集使用数据。用 Kilo 模型时，内容会传到Kilo AI 处理。详见 [PRIVACY.md](../PRIVACY.md)。
