这是一份只供开发参考的小岛动画小样（v4），不是产品代码，请不要直接并进应用。

## 文件

- `index.html`：可在浏览器里直接打开的 v4 小样（6 倍放大，按空格或「再看一遍」重播）
- `preview-v4.mp4`：6 倍放大，按顺序走一遍全部状态（约 40 秒）
- `frames-v4.png`：3×3 帧格图（idle / drowsy / asleep / wake / expect / read / think / write / done）

## 动法参数

各状态动法以 SID1-276 评论 `9067f0f3` 的最新版为准。开发时请按该评论实现，不要照抄小样代码里尚未改正的旧数字。

要点：

- 只有两只眼睛。不要底边细光，不要睡熟的「z」，岛上不加文字。完成时用细线 `^ ^`（不填色，描边 `#f5f1e8`、线宽 1.4），不要饱满填色的弯月。
- 岛 112×30，机身 `#22201c`，眼睛 `#f5f1e8`。待命静止时两眼等大，半径 5.3（与 0.3 一致）；做动作时可以一大一小、一高一低。
- write：点头小跳约 **1 秒一拍**（小样代码仍是 `sin(6t)`，那是旧数字，开发不要用 6Hz）。
- read 下蹲：约 **0.4px**（小样仍是 0.7px）。
- done 轻跳：目标峰值 **4.2px**，不超过 5px（小样实测约 4.2–4.7px，开发时把冲量调到 4.2）。
- 跳动一律不超过 5px。
- 动法用弹簧追目标，过渡会过冲回弹；闭眼快、睁眼慢，上下眼皮分开动；两眼眨得不同步，右眼大约晚 30ms。

状态顺序与小样一致：idle → drowsy → asleep → wake → expect → read → think → write → done。各状态的视线、眼型和不对称细节见评论 `9067f0f3`。
